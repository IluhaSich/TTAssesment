# TTAssesment

Сервис оценки качества учебного расписания РУТ (МИИТ). Приложение парсит расписание
групп с сайта университета и выставляет каждой группе оценку — насколько её расписание
удобно для студентов. Дальше расписания можно сравнивать между собой и находить
самые удачные и самые неудачные.

Оценка складывается из девяти независимых критериев: время начала и окончания пар,
«окна» между парами, наличие длинного перерыва, дневная нагрузка, её равномерность
по неделе, количество учебных дней и распределение выходных. За нарушение каждого
критерия начисляются штрафные баллы.

Веса критериев зависят от ступени обучения: младшим курсам бакалавриата лучше подходят
ранние пары, старшим курсам и магистратуре — поздние, поэтому одно и то же расписание
получает разные оценки для разных групп.

Каждый критерий — отдельный класс, реализующий общий интерфейс `EvaluationCriterion`;
Spring собирает их в список и передаёт в оценщик, так что добавление нового критерия
не требует правок существующего кода. Парсинг и оценка групп идут параллельно
в пуле потоков.

## Стек

Java, Spring Boot (Web, Data JPA), PostgreSQL, jsoup (парсинг расписания), Thymeleaf,
ModelMapper, Maven.

## Запуск

Нужна доступная база PostgreSQL, параметры подключения задаются через `.env`.

```bash
cd tta && ./mvnw spring-boot:run
```
